# WrapUpBlooms &bull; Luxury Floral Boutique Shopify Theme (OS 2.0)

A bespoke, fully animated, high-conversion Shopify Theme tailored for **WrapUpBlooms** &mdash; migrating from Etsy to an independent branded online flagship store.

---

## 🌸 Visual Aesthetic & Motion Highlights
- **Palette**: Romantic Silk Cream (`#FFF9F5`), Whispering Blush (`#FFF0F5`), Dusty Rose Gold (`#C47B89`), and Champagne Gold (`#D4AF37`).
- **Interactive Floating Petals Physics (`floating-petals.js`)**: Real-time canvas engine with fluttering cherry and rose blossom petals, mouse-reactive garden breeze physics, and an on/off toggle pill.
- **Fluid Water Flowing Wave Dividers (`water-ripple.js`)**: Organic undulating SVG current transitions between sections that create an uninterrupted, liquid water-flowing experience.
- **Interactive Live Engraving Customizer**: Customers can type any name or custom script, select their recipient's birth month flower (all 12 botanical months), and see the live engraved mockup in real-time before adding directly to cart.
- **Slide-out AJAX Cart Drawer**: Dynamic progress meter for free gift packaging/shipping, custom engraving badge tags, instant subtotal calculation, and direct checkout CTA.
- **Typography**: Editorial luxury serif (`Playfair Display`) paired with clean modern sans-serif (`Plus Jakarta Sans`).

## 🚀 How to Set Up in Shopify (5-Minute Migration)

### Step 1: Upload the Custom Theme
1. In your Shopify Admin, navigate to **Online Store** &rarr; **Themes**.
2. Under the *Theme library* section, click **Add theme** &rarr; **Upload zip file**.
3. Select `WrapUpBlooms-Shopify-Theme.zip` and click **Upload file**.
4. Once uploaded, click **Actions** &rarr; **Publish** (or **Customize** to preview and adjust branding).

### Step 2: Import the Product Catalog
1. In your Shopify Admin, navigate to **Products**.
2. Click **Import** at the top right.
3. Select `shopify_products_wrapupblooms.csv` and click **Upload and continue**.
4. Review the product preview and click **Import products**.

### Step 3: Set Up Payment Gateways
1. Navigate to **Settings** &rarr; **Payments**.
2. Activate **Shopify Payments** (Credit Cards, Apple Pay, Google Pay) and **PayPal Express Checkout**.
